## 1. 목표
축구 경기 데이터로 **3D 애니메이션 영상(MP4)** 을 만든다. 유튜브 분석 콘텐츠에 쓴다.
참고 화면: 월드컵 반자동 오프사이드 기술(SAOT) 중계 그래픽처럼, 회색·단색 마네킹 선수가 3D 경기장 위에서 움직이는 장면.

만들고 싶은 영상 예시
1. **실제 장면 재현**: 골 장면을 3D로 재현하고 카메라를 돌려가며 보여준다.
2. **더 나은 선택지**: 실제 플레이 뒤에 반투명 "유령 선수"로 대안 플레이를 겹쳐 보여주고, 성공 확률을 자막으로 띄운다.
3. **몸 방향 분석 (장기)**: 공을 받는 선수의 골반·디딤발 방향을 보여주고, 다음에 어느 쪽으로 치고 나갈지 표시한다.

## 2. 현재 상태 (이미 있는 것)
- `animation/play_animation.py`: Metrica 공개 추적 데이터로 **2D** 골 장면 MP4 생성 (mplsoccer + Matplotlib).
- 데이터 읽기 함수 `load_tracking(game, team)`: 프레임별 모든 선수와 공의 위치를 **미터 단위**로 반환.
  - 경기장 105 x 68 m, 원점은 왼쪽 아래, 초당 25프레임
  - 열 이름: `Home_{등번호}_x`, `Home_{등번호}_y`, `Away_{등번호}_x`, `Away_{등번호}_y`, `ball_x`, `ball_y`
  - 화면 밖 선수는 NaN
- 이벤트 함수 `load_events(game)`: 패스·슈팅 등 이벤트와 시작·끝 프레임.
- 데이터 파일은 `data/metrica/`에 있고 Git에는 올리지 않는다. 받는 곳: https://github.com/metrica-sports/sample-data
- 실행 환경: Windows 11, Python 3.14 가상환경(`.venv`), GPU RTX 5060 Laptop 8GB.

**추적 데이터에는 선수 "위치(점)"만 있고 관절(자세)은 없다.** 3D 마네킹의 걷기·달리기 동작은 위치 변화(속도·방향)로 만들어야 한다.

| # | 작업 | 담당 추천 | 이유 |
|---|---|---|---|

| T7 | 영상 포즈 인식 → 3D 관절 → 마네킹에 적용 (몸 방향 분석) | 장기 연구 | 직접 촬영 영상과 정답 표시가 먼저 필요 |

## 4. 세부 요구사항

### T3. 추적 데이터 → Blender 키프레임
- 입력: `load_tracking()` 결과(프레임 범위 지정), 장면 시작·끝 프레임
- Blender 좌표 변환: 경기장 중앙을 원점(0,0,0)으로, x축 = 경기장 길이, y축 = 너비, 1 Blender 단위 = 1 m
- 선수마다 마네킹 1개, 공 1개. 25fps 데이터를 Blender 25fps 타임라인에 그대로 대응
- NaN 구간은 마지막 위치를 유지하고 숨김 처리
- 실행 방식: `blender --background scene.blend --python build_scene.py -- --game 2 --start 11852 --end 12262` 처럼 **명령줄로 재현 가능**해야 함
- 산출물: `animation/blender/build_scene.py`, 사용법 README

### T4. 동작 선택
- 속도(m/s) 기준 예시: 0~1 서기, 1~4 걷기, 4 이상 달리기 (값은 설정 파일로 조정 가능)
- 선수 몸 방향 = 최근 0.2초 이동 방향. 정지 중이면 공 쪽을 바라봄
- 동작 전환 시 갑자기 바뀌지 않게 블렌딩

### T5. 렌더링
- 1920x1080, 25fps, MP4(H.264)
- Eevee 엔진 우선 (렌더링 속도). 16초 장면 기준 렌더링 30분 이내 목표
- 홈 빨강, 원정 파랑, 득점 선수 노란 윤곽, 공 흰색 + 궤적
- 화면 아래 자막 영역 비워두기 (자막은 편집에서 추가)

### 검증 기준
- 2D 시험작(`output/goal_demo.mp4`)과 같은 장면을 렌더링했을 때 선수 위치와 움직임이 일치
- 선수가 경기장 밖으로 튀거나 미끄러지듯 움직이지 않음(발 미끄러짐 최소화)
- 같은 명령을 다시 실행하면 같은 영상이 나옴

## 5. 제약
- **저작권·초상권**: 중계 영상, 실제 선수 얼굴·이름이 들어간 모델, 구단 로고 사용 금지. 등번호만 표시.
- **데이터 출처 표기**: 영상 끝에 "Tracking data: Metrica Sports sample data" 표기. 공개 전 라이선스 확인.
